This page shows a QR code only when the installer opens it for you, with your connection details attached to the link. The link was missing or incomplete, or you already closed it. That's fine: just ask the installer to show it again on the computer running Hermes.

macOS and Linux

curl -fsSL https://raw.githubusercontent.com/michaeldimuro/hermes-mobile/main/install/install.sh | bash -s -- --pair

Windows (PowerShell)

$env:HERMES_MOBILE_PAIR=1; irm https://raw.githubusercontent.com/michaeldimuro/hermes-mobile/main/install/install.ps1 | iex

Haven't installed yet? Start with the setup guide.
